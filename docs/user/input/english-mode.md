## 进入英文模式

- **macOS**：`Caps Lock` 亮起为英文模式，熄灭回到中文。
  想让 `Caps Lock` 像系统拼音那样在青简与「ABC」之间切换输入法，在「系统设置 → 键盘 → 文本输入 → 编辑」里打开用 Caps Lock 切换「ABC」的选项：
  轻按 `Caps Lock` 切换输入法，按住仍是大写锁定；这时青简自己的英文模式就用不到了。
- **Windows**：单击 `Shift`（按下即松开，不与其他键组合）在中 / 英之间切换，任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」。
  反向同样有效：点击任务栏的「中 / 英」图标，青简随之切换（悬浮状态条一并更新）。
  中英模式缺省**所有应用共用一份**：在一个应用里切到英文，切到别的应用、新打开的应用也是英文；也可以按应用分别记住，见下文。
  右键这个图标弹出菜单：切中文 / 英文、全角标点、显示或隐藏悬浮状态条、打开符号面板、打开设置或旧版设置。
  `Caps Lock` 在 Windows 上只控制大小写：亮起时无论中英模式均直接输出大写英文字母（与微软拼音一致）。英文模式下 `Shift` + 字母也直接输出大写；
  中文模式下 `Shift` + 字母缺省是临时打英文：拼音先上屏，这个大写字母原样交给应用；「设置 → 中英文」的「Shift + 字母」可改成进组句参与匹配（见[按键](../getting-started/keys.md)）。
- **Linux（Fcitx5 / Fcitx4）**：单击 `Shift` 在中 / 英之间切换，按住 `Shift` 打字母不会切换。中英模式**每个窗口各记一份**，新打开的应用或窗口从中文开始，可改成从英文开始，见下文。
  `Caps Lock` 亮着时直接输出大写英文字母。

### 默认模式与按应用记忆

「设置 → 中英文」的「英文」一组里有两项：

- **默认英文模式**：Windows 上青简启动时从英文开始；Linux 上新打开的应用和窗口从英文开始。关掉时从中文开始。
- **按应用记住中英模式**（仅 Windows）：切回应用时恢复它上次的状态。没有记录的应用使用上面的默认模式，同一应用的多个窗口共用状态。

按应用记住的状态在本次青简运行期间保留，关闭再打开应用仍能恢复；重启青简后重新使用默认模式。
更改这两项或开关「英文模式」会重置已记住的状态；修改字体、标点等其他设置不会重置。
关掉「英文模式」时始终使用中文，默认英文不生效。

在配置文件的 `[general]` 中，两项分别是 `default_english` 和 `remember_mode_per_app`，缺省都是 `false`。
例如同时设为 `true`，新应用从英文开始，在记事本切到中文不会影响浏览器的英文状态。

### 改掉或关掉中 / 英切换

打字时误触 `Shift` 会切到英文、打断输入，可以在「设置 → 中英文」的「切换键」里调整（配置 `[shortcut] switch_mode`，如 `["shift", "control"]`）。
下面几个键勾上哪个就能用哪个，可以多选：

| 选项 | 行为 |
|---|---|
| 单击 Shift | 缺省勾上，与微软拼音一致 |
| 单击 Ctrl | 不容易误触；Ctrl 在其他组合键里的作用不受影响 |
| Ctrl + Alt + Space | 组合键，最不容易误触 |

一个都不勾时键盘不再切中英：Windows 上只能用任务栏 / 悬浮状态条上的「中」「英」按钮；Linux 上单击 `Shift` 原样交给应用，
要打英文可以用 Fcitx 自己的切换热键切到英文键盘（Fcitx5 缺省 `Ctrl + Space`）。
Fcitx5 缺省还把**左** `Shift` 设为「临时在当前和第一个输入法之间切换」（Temporarily switch between first and current Input Method），
它比青简先拿到按键：单击左 `Shift` 会直接切到英文键盘，不受青简的切换键设置影响。想让左 `Shift` 只归青简管或彻底不切，
到 Fcitx5 配置的「全局选项 → 快捷键」把这一项清空。

Windows 上 `Ctrl + Space` 不在其中：它是 Windows 自带的「输入法/非输入法切换」，青简跟着它切中英（与微软拼音一致），不用勾、一直可用。
装了英文键盘或别的输入法时，Windows 可能改用它直接切到别的输入法，这由系统决定；不想要这条系统热键，到「设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键」把它改成「未分配」。

如果习惯中英文用两个不同的输入法，可以关掉「设置 → 中英文」第一行的**英文模式**开关（配置 `[general] english_mode`）：
关掉后青简固定中文，切换键与状态栏按钮都不再切到英文，默认英文模式也不生效。需要英文时 Windows 用 `Win + Space`、Linux 用 Fcitx 的切换热键切到别的输入法；
Windows 语言栏上的「中 / 英」图标也不再出现。

两项都是**改完立刻生效**：输入法进程会盯着配置文件，变更后一秒内重新读取。

## 悬浮状态条（Windows）

任务栏的「中 / 英」不易察觉时，可另开一条**桌面上的悬浮状态条**：「设置 → 中英文」打开「悬浮状态条」。它有四格：

| 格 | 显示 | 点击 |
| --- | --- | --- |
| `中` / `注` / `英` | 当前模式（选了大千注音时显示「注」；双拼、五笔这类非全拼方案显示为「中 · 小鹤双拼」） | 切换中 / 英，与单击切换键相同；关掉「英文模式」后这一格固定「中」，点了也不切 |
| `，。` / `,.` | 当前模式下标点是否转为全角。中英各记一份，缺省中文全角、英文半角，切换模式时随之切换 | 切换当前模式的全角 / 半角 |
| `符` | | 打开[符号面板](shortcuts.md#符号面板) |
| ⚙ | | 打开设置 |

按住拖动可移到屏幕任意位置，位置会被记住；外观随系统的深浅色与缩放。大小在「状态条大小」里调（60%–150%），不跟候选字号走。
它只在当前输入法为青简时显示：切换到微软拼音等其他输入法，或切到系统的英语键盘布局（任务栏显示「ENG」）时收起，切回后再次出现；关闭某个应用不影响它。它与任务栏图标并存。
前台是全屏应用（游戏、全屏看视频、演示）时自动收起，退出全屏后回来。也可以在任务栏「中 / 英」图标的右键菜单里随时显示或隐藏它。

## 行为

英文模式下输入字母时，候选窗口给出英文词的补全与拼写纠正：`recieve` → receive，`seperate` → separate。
字母缺省小写，按住 `Shift` 输出大写。

选词与中文模式一致：`Space` 选高亮候选（词上屏后空格照常输入），数字键选当前页第 N 个（没有第 N 个时数字接进单词，如 `foo1`），翻页键翻页，`↑` / `↓` 移动高亮，`Tab` 同样选高亮项。
**`Enter` 与标点将所敲字母原样上屏**：`kubectl` 这类词表中没有的词按 `Enter` 即可原样输出；没有候选时 `Space` 也原样上屏。
带数字的标识符（`mp3`、`utf8`）先按 `Enter` 输出字母再敲数字；没有候选时数字直接接在字母后。

标点在 macOS 上一律半角；Windows 上缺省半角，需要全角时见上文悬浮状态条。

## 记住用户的词

按 `Enter` 原样上屏过的英文词（如 `gist`、`python`）会记入个人词表，下次输入时排在首位。选过的英文候选同样记录。

中文模式下 `key`、`id` 这类末尾落单一个字母、既像英文词又可读成拼音的输入，若常选中文词（如「客一」「以的」），中文词排在前面，英文词退后；
勾选「中文候选排在英文词前面」后中文词一律在前。

## 关闭

- 全局：「设置 → 中英文」关闭「英文模式也给候选」。关闭后为纯直通，与未使用输入法时一致。
- 按应用：缺省只在浏览器、聊天和文档类应用中给候选，例如 Safari、Chrome、Edge、Firefox、微信、QQ、企业微信、钉钉、飞书、Word、WPS、记事本、备忘录、Obsidian。
  其他应用中英文模式为纯直通，字母原样交给应用：终端与代码编辑器里不会遮挡应用自身的补全或占用 `Tab` 键，
  Windows 上 Photoshop、Illustrator、SolidWorks、Blender 这类软件的单键快捷键（如 Photoshop 的 `W` `H` `V`）也能直接使用。
  「中英文」页的「只在写字的应用里给」控制此名单，取消勾选即处处都给。需要增减具体应用时，在「高级」页打开配置文件，修改其中 apps 一段，每一项均附说明。

## 与中文模式的关系

中文模式下整段输入为英文词时同样直接给出英文候选（`hello` 先英文再拼音，勾选「中文候选排在英文词前面」后英文排第二），拼音不成立时还会补全前缀（`compa` → company）；取消勾选「输入拼音时也给英文词和补全」后中文模式只出中文。
无需切换到英文模式，见 [快捷输入](shortcuts.md)。

## 中西文自动空格

macOS 与 Windows 可打开「设置 → 中英文 → 中文与英文、数字之间自动加空格」（缺省关）。勾选后，汉字与半角字母、数字相邻处自动补一个空格：
「用Go写了30行」上屏为「用 Go 写了 30 行」。标点与已有空格两侧不补，自定义短语与日期、算式这类快捷候选按原文上屏；若光标移到了别处，或应用不提供光标前的文字，则无法判断上文，不补空格。
Linux 暂不支持。

## 本地分支的可选英译中原型（Windows）

本地分支可在配置文件 `[general]` 中设置 `english_to_chinese = true`，缺省关闭，设置页暂不提供控件。
它沿用原生英文模式，并受英文候选开关和应用白名单控制；中文拼音模式保持原样。

输入 `studio`，中文“工作室”会作为主候选，按 `Space` 提交高亮候选，不追加尾空格。
每个已收录的中文义项各为一个完整候选，沿用原有分页，末尾始终保留英文原文候选；`Enter` 始终提交实际输入。
中文主候选的辅助注记只显示一次英文来源，保留该义项的词性；原有「译词词性标注」开关决定是否显示 `n.`、`v.` 等。
例如 `tear` 的“撕”标 `v.`，“眼泪”标 `n.`；关闭词性标注后仍保留英文来源与中文候选。
`may` 给“可能、可以、五月”三个独立候选，逐义保留词性；大小写折叠保持原样，不按上下文自动消歧。
完整短语 `"look up"` 给“查阅、好转”，`"ice cream"` 给“冰淇淋”。这些均是有限词条，不是整句翻译。
只有完整查表命中才给中文，不用补全词或纠错词的释义代替当前英文。
未知词、前缀和错拼只保留原文，不会显示不相关中文。只有原文候选时数字也留在输入中，例如 `bankk1`。

含空格的短语先输入英文半角双引号，例如 `"set a record"`。
引号内空格留在组词中，闭合引号后再按 `Space` 提交“创造纪录”；未闭合引号时只保留原文。
这是有限的本地短语表，不提供整句翻译。词表按已收录义项查询，仍有漏义；大小写折叠不能识别专名。
普通英文或拼音候选旁的多义译文仍是辅助注记；既有第一、第二义快捷键保持原样。
关闭该开关即可恢复原生英文补全与纠错。


### 英译中的个人排序（本分支）

打开学习时，同一英文下选过的中文译词会按累计选择次数靠前。没有个人记录时，
`bank` 先给“银行、河岸”；选择“河岸”并成功上屏一次后，下次是“河岸、银行”。
这项选择保存在原有个人学习数据中，重新启动后继续使用。大小写共用记录；不同单词和完整短语各自独立。
如果另一义项已有更多选择次数，一次新选择不保证超过它；未选过的义项保持原有顺序。

只调整当前词表已有的译词，不补造词义，也不改变拼音与普通英文补全的个人排序。
浏览候选、取消、按 Enter 提交原文不计为中文译词选择；私密输入或关闭学习时不新增记录。
Windows 只有配套新版组件确认文本写入成功后才计数，旧组件没有确认时照常输入但不学习此偏好。
写入确认丢失或存储失败可能使本次选择未保存；这项功能不会开启输入日志、联网或自启。
