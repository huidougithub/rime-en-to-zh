# 选词学习组件更新边界

英译中选择复用上游学习器，机制与测试见 [选词接入](english-translation-choices.md)。本页是通用升级说明，不包含私人安装路径、进程或学习状态。

更新时应使用协议 11 的配套 Server 与 x64/x86 TSF DLL，保留现有配置、正式词库、模型、两套设置程序及个人学习文件。不得用自动测试数据覆盖真实 `user-choices.tsv`。

DLL 注册路径改变后，已经打开的应用可能仍加载旧模块。只重启 Server 不能使这些宿主使用新版 DLL；应让用户保存工作并自行退出重开相应应用，或自行选择重启系统。无需改变默认输入法、自启、日志或云设置。

旧 DLL 可继续普通输入，但不会发送新提交确认，因此不学习这项译词偏好。记录确认成功不代表磁盘写回必然成功，I/O 错误仍由原有学习器报告。

最短手工验收：在干净学习数据的测试环境输入 bank，选择第二项“河岸”并按 Space；下一次同词应优先“河岸”。Enter 原文不计；重启测试后台后已落盘的排序保持。已有较高累计次数时仍按原生次数排序，不保证一次选择覆盖全部历史。

回退需恢复配套后台和 DLL，并保留配置及所有个人数据。若同时更新了多义英汉表，还须恢复与旧读器兼容的 `.qj`，见 [多义项兼容](multiple-senses.md)。本仓库不提供面向某台电脑的自动部署或回退状态文件。
