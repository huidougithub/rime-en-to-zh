# Windows 英译中验收规程

这是可复现的操作规程，不是所有项目均已通过的实机记录。先按 [Windows 构建说明](../../apps/windows/README.md) 构建配套组件，检查正式资源和许可，参照 [完整组件说明](windows-full-restoration.md)。编译、CLI 与服务测试不能替代 TSF 文本框验收。

本分支保留上游 TSF 标识、管道和用户目录，不能原样与另一套青简独立并存。安装或注册前应选择干净测试环境，或明确协调当前安装升级；保留其他可用输入法及个人数据。不自动改变默认输入法、设置自启或重启电脑。

## 操作

1. 在获准的测试安装中使用配套 Server、x64/x86 DLL、设置程序及正式资产，不以样例资源替代完整资源。
2. 可参考完整离线预设 `examples/english-to-chinese-windows.toml`。确认 `english_to_chinese=true`、英文候选及当前应用规则开启；学习测试需要 `learning=true`。离线测试不配置密钥、不启用云、自动更新或输入内容日志。
3. 完全退出旧测试应用后新开记事本，用 Win+Space 手动选择青简，关闭 Caps Lock。若显示“中”，轻点 Shift 切到青简内部“英”；这不是系统纯英文直通。
4. 查看候选后再提交，分别记录输入、候选、词性、实际上屏、应用与系统版本。

| 输入/操作 | 预期 |
| --- | --- |
| `apple` + Space | 主候选“苹果”，提交“苹果” |
| `studio`、`thwart` | “工作室”、“挫败”，不得为“学习”、“银行” |
| `set` | “设置、放置”，不得出现脱离短语限定的“创造” |
| `bank` 选择第二义 + Space | 无个人记录时“银行、河岸”；选择“河岸”成功后同词前置 |
| 再查 bank，Enter | 提交实际原文，不新增中文译词计数 |
| 重新启动测试后台再查 bank | 已成功落盘的选择顺序保留；不在真实个人数据中自动注入测试记录 |
| `may` | “可能、可以、五月”三个独立候选，逐义词性可见 |
| `tear` | “撕”标 v.，“眼泪”标 n.；关闭词性开关后来源仍只显示一次 |
| `STUDIO` + Enter | 保留实际大小写原文 |
| `bankk1`、`studoi`、`zqxjkvv` | 只有原文，无伪造译义 |
| `"set a record"` + Space | 完整短语提交“创造纪录”，内部空格不中途选词 |
| `"look up"`、`"ice cream"` | 分别有“查阅、好转”和“冰淇淋” |
| 未闭合或未知短语 | 原文路径，Enter 保留实际引号 |
| 切回“中”，`nihao` | 保留原有拼音输入 |
| 关闭 english_to_chinese | 恢复原生英文补全与纠错 |

多义词可存在未收录义项；以 [固定集](../../tests/english_to_chinese/cases.tsv) 区分已知漏义和错译。候选排名正确不是语义完整性证明。

另列 Word、浏览器、32 位应用、密码框、跨 DPI、繁体、不同键盘布局、提权应用及组合键的实际结果。注册成功也不证明所有宿主已加载新版 DLL；宿主须自行退出重开，不能强关用户应用。

## 回退

先保存工作并切到其他输入法，恢复配套旧后台、DLL 和对应旧版英汉 `.qj`；不删除配置或个人学习数据。多义 v2 `.qj` 不能交给旧读器，见 [兼容说明](multiple-senses.md)。本规程不自动执行注册、回退或系统重启。
